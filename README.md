# ai-crm-feeder

Alimentador Inteligente de CRM con IA — automatiza la captura de información
de clientes en EspoCRM a partir de texto libre (notas de llamada, correos),
usando una API de IA para extraer y estructurar los datos antes de guardarlos.

Proyecto de estadías (UTT) desarrollado para Digiproduct.

## Stack

- Backend: Django + Django REST Framework
- Base de datos: MySQL
- Frontend: HTML, CSS, JavaScript, Bootstrap
- IA: [API por confirmar]
- CRM: EspoCRM (vía API REST)

🚧 En desarrollo — fase de planeación.

## Módulos

- Autenticación
- Captura (manual y texto libre)
- Extracción con IA
- Revisión de datos
- Integración con EspoCRM
- Historial y logs
